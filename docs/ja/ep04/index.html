第4話

タイガと おじいちゃんのボール

文字の大きさ
⏱ 約13分

金曜日の朝。いつもなら校舎じゅうに響(ひび)きわたる大声が、どこにも聞こえなかった。

「……はあぁぁぁ……」

五年二組の教室のまんなかで、深く重いため息がひとつ。

机に突(つ)っ伏(ぷ)してペシャンコになっているのは、緑のサッカーユニフォームを着た犬飼(いぬかい)タイガだ。鼻の頭のばんそうこうが、心なしか元気をなくして曲がっている。

「犬飼くん、朝からため息なんて珍(めずら)しいわね。まるで空気の抜(ぬ)けた風船のようだわ」

登校してきた学級委員長の九条(くじょう)アヤメが、革の推理ノートを抱(かか)えながら眉(まゆ)をひそめた。

「タイガ、どうしたの？　風邪(かぜ)でもひいた？」

星川(ほしかわ)こはるが心配して机をのぞきこむと、タイガはのっそりと顔を上げた。その目は真っ赤に腫(は)れあがっている。

「こはる……委員長……オレ、もうおしまいだ……」

「おしまいって何が！？　あした、秋のジュニアサッカー大会の準決勝でしょ！」

「その大会に出られねーかもしれないんだよ……」

タイガは涙(なみだ)声で、絞(しぼ)りだすように言った。

「ボールが……なくなったんだ」

「ボール？」

「ゲンじいちゃんにもらった、大切なボールだ！　元サッカーコーチのじいちゃんが、オレが初めてサッカーを始めた日に買ってくれた、革のサッカーボール……チームのみんなの寄せ書きも書いてある、オレの宝物なんだよ！」

タイガはおじいちゃん子だ。豪快(ごうかい)で厳しいゲンじいちゃんだけど、タイガが練習で泥(どろ)だらけになって帰ると、いつも大笑いしながら頭をなでてくれる。

「『ボールは丸いんだから転がってナンボだ！』って笑いながら、じいちゃん、毎晩オレのボールを古いクリームでピカピカに磨(みが)いてくれてたんだ。あのボールを蹴(け)ると、足の先から力が湧(わ)いてくるんだよ。明日の試合、あのボールをベンチに置いて一緒(いっしょ)に戦う約束だったのに……昨日、練習のあとにどこかへ転がっていっちまって……」

タイガは机に顔をうずめて肩(かた)を震(ふる)わせた。

こんなに小さくなったタイガを見るのは、初めてだった。

こはるはアヤメと顔を見合わせた。

「探そう、タイガ！　わたしたち『わすれもの探偵団(たんていだん)』でしょ！」

「星川さんの言う通りだわ」

アヤメがメガネの奥(おく)の瞳(ひとみ)をキリリと光らせ、すみれ色の「わすれな手帳」を開いた。

「仲間が困っているのを見過ごすのは、探偵団(たんていだん)の名折れよ。犬飼くん、最後にボールを見た場所へ案内なさい！」

タイガはパッと顔を上げ、涙(なみだ)をゴシゴシとユニフォームの袖(そで)でぬぐった。

「お前ら……！　ありがとう！」

放課後。

こはるたち三人は、月見坂の下を流れる川沿いのグラウンドへやってきた。

広い芝生(しばふ)と土のグラウンド。昨日の夕方、タイガが一人でシュート練習をしていた場所だ。

「練習が終わったのは五時前だったぜ。最後に強烈(きょうれつ)なロングシュートを放ったら、ゴールの枠(わく)に当たって大きく跳(は)ね返って……草むらの方へ消えちまったんだ」

「ふむ……昨日は強い南風が吹(ふ)いていたわね」

アヤメが手帳にペンを走らせる。

「土の傾斜(けいしゃ)と風向きから計算すると、ボールは土手を転がり落ちて、川沿いの遊歩道へ向かったはずだわ」

「くんくん……！　待てよ！」

タイガが四つんばいになり、地面に鼻を近づけた。

「犬飼くん、ですから地面を嗅(か)ぐのはおやめなさいと……」

「ちがうって！　オレの汗(あせ)のにおいと、じいちゃんがいつもボールに塗(ぬ)ってくれた古い革用クリームのにおいがする！　あっちだ！」

タイガが立ちあがり、川沿いの茂(しげ)みへ向かって駆(か)けだした。

「すごい鼻ね……理屈(りくつ)を超(こ)えているわ」

アヤメがあきれつつも感心している。

こはるのポケットから、ポッケがピョコンと顔を出した。

『こはる！　ボクもなんかにおうポケ！　革のにおいと……古い泥(どろ)のにおいだポケ！』

「急ごう！」

タイガの鼻とアヤメの計算をたどって下流へ進むと、道は月見坂の線路の下をくぐる古いレンガ造りのトンネルへと突(つ)き当たった。

昼間でも薄暗(うすぐら)く、壁(かべ)には青いコケが生えている。

天井からはポタ、ポタ……と冷たい水滴(すいてき)が滴(したた)り落ちていた。

『ヒエ〜ッ！　ジメジメして毛糸が縮んじゃうポケ〜！』

ポッケが悲鳴をあげてこはるのフードに潜(もぐ)りこみ、ひもをキュッと引っぱって鼻先だけを出した。

「こ、ここは……」

先頭を走っていたタイガの足が、ピタリと止まった。

生まれたての小鹿のように、膝(ひざ)がガクガクと音を立てて震(ふる)えだす。

「ど、どうしたのタイガ？」

「で、出た……坂の下の、おばけトンネルだあぁぁ……！」

タイガの顔から血の気がサーッと引いていた。

「上級生が言ってたんだ……昔のトンネルで、夕方になると壁(かべ)から手が生えてきて引きずりこまれるって……！　オ、オレ、無理！　絶対に入りたくねえぇぇ！」

「さっきまでの威勢(いせい)はどこへ行ったのかしら、犬飼くん」

アヤメが腕(うで)を組む。けれど、そのアヤメも薄暗(うすぐら)いトンネルの奥(おく)を見つめて、少しだけ背筋をこわばらせていた。

「も、もちろん、幽霊(ゆうれい)など非科学的な迷信ですけれど……少し気味が悪いわね」

「大丈夫(だいじょうぶ)だよ、ふたりとも！　手をつなごう！」

こはるはタイガとアヤメの手をぎゅっと握(にぎ)った。

「タイガの大事なボールが、この中で待ってるんだもん！」

そのときだった。

コーン、コーン、コーン……。

町のスピーカーから、午後五時のゆうやけチャイムが響(ひび)きわたった。

夕暮れの空が朱色(しゅいろ)から紫(むらさき)へ染まり、トンネルの入り口に、濃(こ)いたそがれの影(かげ)が落ちる。

『……タイガ……タイガ……どこなの……？』

トンネルの奥(おく)から、かすかな声が響(ひび)いてきた。

『……暗いよ……冷たいよ……いっしょに、ゴールネットを揺(ゆ)らしたいよ……』

「ボールの声だ！」

こはるが叫(さけ)ぶと、タイガが息をのんだ。

「ボ、ボールが……オレの名前を呼んでるのか……！？」

「うん！　タイガを待ってる！」

「行くぞ！」

タイガは恐怖(きょうふ)を振(ふ)り切るように叫(さけ)び、トンネルの中へと飛びこんだ。

トンネルの中は、外よりもずっと冷えこんでいた。

足音がペタペタと反響(はんきょう)する。

奥(おく)へ進むと、線路の真下あたりで、黒い霧(きり)がモヤモヤと渦(うず)を巻いていた。

そして――。

ボフンッ！　ボフンッ！

暗闇(くらやみ)の中から、無数のボールが弾(はず)むような不気味な音が近づいてきた。

「ひゃああっ！？」

ポッケがこはるのフードの中へ潜(もぐ)りこむ。

黒い霧(きり)の中から現れたのは、巨大(きょだい)な怪物(かいぶつ)の姿だった。

それは、泥(どろ)まみれになった何十個もの古いボール――真っ赤なドッジボール、毛羽立ったテニスボール、古びたゴムボールが、黒いもやで一つに固まった『ボールだるま』のノラモノだった！

ゴロゴロと巨大(きょだい)な車輪のように回転しながら、地面を揺(ゆ)らして迫(せま)ってくる。

そして、その巨大(きょだい)なだるまの胸の真ん中に――。

無数のサインが書かれた、タイガの白黒のサッカーボールが、黒い霧(きり)に絡(から)め取られて泣いていた。

『タイガ……たすけて……！』

「ボール！」

タイガが叫(さけ)んだ。

ノラモノは怒(おこ)ったようにうなり声をあげ、巨大(きょだい)な体をバウンドさせてこはるたちへ突進(とっしん)してきた！

ズドォォン！

トンネルの壁(かべ)にぶつかり、レンガのかけらがパラパラと落ちる。

「ひ、ひいぃぃっ！　でかい！　押(お)しつぶされちゃうぜーーっ！」

タイガが腰(こし)を抜(ぬ)かしかけ、後ずさる。

「逃(に)げちゃダメ、タイガ！」

こはるは叫(さけ)び、タイガの腕(うで)を強く引いた。

「ボールの声を聞いて！　ボールが言ってるよ！」

「えっ……？」

「『タイガが初めてゴールを決めた日、おじいちゃん、泣いて喜んでくれたんだよ。タイガの笑顔が大好きだから、明日もいっしょにゴールネットを揺(ゆ)らしたいよ』って！」

星めがねから伝わってくるボールのきおくを、こはるは力いっぱいに叫(さけ)んだ。

「あのボールは、おじいちゃんの愛と、タイガの夢が詰(つ)まった、世界にひとつの宝物なんだよ！」

タイガの瞳(ひとみ)が大きく見開かれた。

その目から、ボロボロと大粒(おおつぶ)の涙(なみだ)があふれ出した。

――オレが初めてシュートを決めた日。

普段(ふだん)はちっとも笑わないゲンじいちゃんが、くしゃくしゃの顔で泣いて、オレを抱(だ)きしめてくれた。

『よくやったぞ、タイガ！　お前はオレの最高のストライカーだ！』

「……そうだ」

タイガの膝(ひざ)から震(ふる)えが消えた。

拳(こぶし)をぎゅっと握(にぎ)りしめ、地面を強く踏(ふ)みしめる。

「オレは……無敵のストライカーだ！　相棒を置いて逃(に)げ出せるかよーーっ！」

タイガが猛然(もうぜん)とダッシュした。

突進(とっしん)してくる巨大(きょだい)なノラモノの正面へ、恐(おそ)れを知らずに飛びこんでいく！

「犬飼くん、危ないわ！」

アヤメが叫(さけ)ぶ。

けれどタイガは止まらない。

転がってくる怪物(かいぶつ)の足元へ、見事なスライディングで滑(すべ)りこんだ！

ズザーーーッ！

タイガの右足が、怪物(かいぶつ)の回転の軸(じく)をピタリと止める。

バランスを崩(くず)したノラモノの胸元から、タイガのサッカーボールがポーンと高く跳(は)ね上がった！

「こはる！　今だーーっ！」

タイガの叫(さけ)びがトンネルに木霊(だま)する。

「その"わすれもの"、わたしが届けます！」

こはるは左手をかざした。

「ポッケ、いくよ！」

「まかせるポケ！」

ポッケが左手にはまり、星めがねを掲(かか)げる。

「星めがね、オープン！」

キィィン――！

星めがねの光が暗いトンネルを真昼のように照らしだした。

夕焼けオレンジの探偵(たんてい)ケープがひるがえる。

こはるは空中に浮(う)き上がったサッカーボールと、取り残されたボールだるまを見つめた。

レンズの向こうに、何十個ものボールたちのきおくが流れこんでくる。

放課後の校庭。川原でのキャッチボール。泥(どろ)だらけの笑顔。

失くされて、暗い草むらや溝(みぞ)に落ちて、誰(だれ)にも迎(むか)えに来てもらえなかったボールたちの涙(なみだ)。

「みんな、たくさん遊んでもらったんだね」

こはるは胸が熱くなって、優しく語りかけた。

「あなたたちを追いかけた子どもたちの汗(あせ)も、笑い声も、消えたりしないよ。ずっと、心の中で生きているよ！」

怪物(かいぶつ)の丸い瞳(ひとみ)が、おだやかに細められた。

「見つけたよ。――おかえり、わすれもの！」

シュパァァァッ！

金色の光の輪がトンネルの中いっぱいに広がった。

黒い霧(きり)がサラサラと消え去り、無数の古いボールたちが、キラキラと輝(かがや)く光の粒(つぶ)へと変わっていく。

『……ありがとう……』

何十人もの子どもたちの声が重なり合って響(ひび)き、光の粒(つぶ)はトンネルを抜(ぬ)け、かつての持ち主たちが暮らす町じゅうの家々へと飛んでいった。

そして――。

ふわりと落ちてきた白黒のサッカーボールを、立ちあがったタイガが両手でしっかりとキャッチした。

「ボール……！」

タイガはボールを抱(だ)きしめ、顔をうずめて泣いた。

「よかった……本当によかったぜ……！」

「犬飼くん、泥(どろ)だらけよ。でも……素晴らしいシュートだったわ」

アヤメが手帳を閉じ、ふっと優しく微笑(ほほえ)んだ。

「へへっ、オレは無敵だからな！」

鼻をすするタイガを見て、こはるとアヤメは笑い声をあげた。

翌日。秋晴れの青空の下。

月見坂運動公園のサッカー場で、秋のジュニア選手権の準決勝が行われていた。

ピーーーッ！

試合終了(しゅうりょう)のホイッスルが鳴り響(ひび)いた瞬間(しゅんかん)、観客席から割れんばかりの歓声(かんせい)があがった。

「やったーーっ！　タイガが決めたーーっ！」

こはるとアヤメは立ちあがってメガホンを振(ふ)った。

後半ロスタイム。タイガの放った強烈(きょうれつ)なボレーシュートが、見事にゴールネットを揺(ゆ)らしたのだ。

決勝進出を決めたタイガは、ベンチの横に置いてあった大切な寄せ書きボールを高々と掲(かか)げ、フィールドを誇(ほこ)らしげに駆(か)けまわった。

スタンドの最前列で、腕(うで)を組んで見ていたゲンじいちゃんが、顔を真っ赤にして涙(なみだ)をボロボロ流しながら叫(さけ)んでいた。

「タイガーーッ！　よくやったぞーーっ！　今日の晩飯は特大のトンカツだーーっ！」

タイガが白い歯を見せて、おじいちゃんに向かって大きく手を振(ふ)った。

その笑顔を見て、胸の奥(おく)がいっぱいに満たされた。

けれど――。

熱狂(ねっきょう)に包まれる観客席のいちばん端(はし)の木陰(こかげ)に、ひとりの少年が静かに立っているのを、こはるは見逃(のが)さなかった。

紺色(こんいろ)の長いコートに、首元の青いマフラー。

銀色のさらさらの髪(かみ)が風に揺(ゆ)れている。夜見くんだ。

こはるのポケットの中で、ポッケが小さく震(ふる)えた。

『こはる……やっぱりあいつがいると、ボクの毛糸がチリチリするポケ……！』

「夜見くん……見に来てくれたのかな……？」

こはるが声をかけようと一歩踏(ふ)み出した瞬間(しゅんかん)、夜見くんは背を向け、人混みの中へと消えてしまった。

その夜。

月見坂の空は、厚い黒雲に覆(おお)われていた。

坂の上の古い洋館の裏の暗闇(くらやみ)で、夜見くん――怪盗(かいとう)ミッドナイトが、冷たい風の中に立っていた。

彼(かれ)の目の前で、黒い霧(きり)がゆらゆらと揺(ゆ)れ、巨大(きょだい)な少女の影(かげ)をつくりだしている。

霧(きり)の髪(かみ)のすき間に、青いワスレナグサの花が妖(あや)しく光っていた。

『ふふふ……カナタ。思い出集めは順調かい？』

幾重(いくえ)にも重なった、甘(あま)く冷たい声が響(ひび)く。

少年は感情を押(お)し殺した声で、懐中時計(かいちゅうどけい)を握(にぎ)りしめた。

「……今夜は収穫(しゅうかく)なしだ。……あと、八十一個」

冷たい風が吹(ふ)き抜(ぬ)け、青い花が暗闇(くらやみ)の中で妖(あや)しく揺(ゆ)れた。

第4話 おわり

次回予告

ポッケ「タイガのゴール、かっこよかったポケ！」

こはる「うん！　でも次の日、冷たい雨の中で小さな女の子が泣いていて……」

ポッケ「片っぽだけの長ぐつを探してるポケ！　でもそこに、あの夜見がやってきて……！？」

こはる「夜見くん、あなたはどうしてそんなに冷たいの？」

こはる「次回、第5話『雨の日の 片っぽぐつ』！」
