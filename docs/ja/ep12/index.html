第12話

その手ぶくろ、ずっと覚えてる

文字の大きさ
⏱ 約16分

それは、いまから五年前の冬のことだった。

月見坂の急な坂道には、赤い冬祭りのちょうちんがズラリと連なり、夕暮れの海風に揺(ゆ)れていた。

屋台からは、香ばしい焼きいもと温かい甘酒(あまざけ)の湯気が立ちのぼり、町じゅうが楽しげな笑い声に包まれている。

カンカンカン、と坂の下の踏切(ふみきり)の警報機(けいほうき)が鳴り響(ひび)いた。

その音に重なるように、夕方五時を告げる『ゆうやけチャイム』が、オルゴールのような優しいメロディを奏で始める。

人混みの中ではしゃいでいた五歳(さい)の星川(ほしかわ)こはるは、焼きいもの甘(あま)いにおいに気を取られているうちに、母のナツミの手を離(はな)してしまった。

「あれ……？　おかあさん？　おかあさーん！　どこー？」

あたりを見回しても、大人の足とコートの波ばかり。

涙(なみだ)ぐみながら坂道を上っていたとき、こはるは、閉まった屋台の暗い陰(かげ)に、小さな人影(ひとかげ)を見つけた。

寒そうに肩(かた)をすぼめ、小さくうずくまっている銀色の髪(かみ)の男の子だった。

薄手(うすで)のジャケット一枚で、靴(くつ)には泥(どろ)がつき、手足は氷のように冷たくなっていた。

男の子は両膝(ひざ)を抱(かか)えこみ、紫色(むらさきいろ)のくちびるをカタカタと震(ふる)わせながら、ポロポロと涙(なみだ)をこぼしていた。

「どうしたの？　迷子になっちゃったの？」

こはるが声をかけると、男の子はおびえた小鳥のように、灰青色の大きな瞳(ひとみ)を上げた。

「……さむい……手が、ジンジンして……すごく痛いよ……」

差し出された男の子の手は、冷たい風にさらされて、真っ赤にかじかんでいた。

五歳(さい)のこはるは、自分の両手を見つめた。

そこには、お母さんが心をこめて編んでくれた、真っ赤な毛糸の手ぶくろがあった。

こはるは迷うことなく、右の手ぶくろをすぽんと抜(ぬ)いた。

そして、男の子の凍(こお)りついた右手に、そっと優しくはめてあげたのだ。

「はい！　これ、かしてあげる！　すっごくあったかいでしょ？」

男の子は目を見張り、自分の右手を見つめた。

赤くて、やわらかくて、まるで陽だまりをそのまま包みこんだような温もりが、冷え切った指先からじんわりと心まで広がっていく。

こはるはにこっと笑い、小さな胸を張った。

「わたし、こはる！　これからお母さんを探して、大人を呼んでくるね。ぜったいに迎(むか)えに来るから！　ずっと覚えてるから、ここで待ってて！」

それが、幼いふたりのあいだで交わされた、たった一つの大切な約束だった。

だが――その夜、無事に大人に保護されて家へ連れ戻(もど)されたこはるは、激しい高熱を出してしまった。

一週間も布団から起き上がれず、夢とうつつをさまよった。

そして熱が引いたとき、幼いこはるの頭からは、あの夕暮れの坂道で交わした約束の記憶(きおく)が、きれいに消え去ってしまっていたのだ。

残された男の子は、冷たい海風が吹(ふ)き抜(ぬ)ける坂の上で、何時間も、何日も待ち続けた。

「迎(むか)えに来る」という言葉だけを信じて。

けれど、通り過ぎる大人たちは、誰(だれ)一人として男の子に気づかなかった。

やがて、百年のさびしさが吹(ふ)きだまる坂の上で、影(かげ)――ワスレナの黒い霧(きり)が、男の子を静かに包み込(こ)んでいった。

そして、町じゅうの人々の記憶(きおく)から、男の子の存在そのものが消えてしまったのだ。

こはるが坂道に落としてしまった左手の赤い手ぶくろは、雪解けの朝、町の人に拾われ、坂の上の『わすれもの館』の棚(たな)へと運ばれた。

いつか持ち主のあたたかい手に戻(もど)りたい。

男の子の手にある、もう片っぽの手ぶくろと再会したい。

五年のあいだ、館の棚(たな)で持ち主を待ち続けた――その一途(いちず)で強い願いが、小さな付喪神(つくもがみ)『ポッケ』を生み出したのだった。

「カナタくん……！」

時計塔(とう)の最上階。

こはるはガラスの時計カプセルに両手を押(お)しあて、大粒(おおつぶ)の涙(なみだ)をポロポロと流しながら叫(さけ)んだ。

「思い出したよ……！　わたし、あなたに右手の手ぶくろを渡(わた)した！　ぜったいに迎(むか)えに行くって約束したのに……高熱を出して、ぜんぶ忘れちゃってたの！　本当にごめんね……！」

冷たいガラスの向こう側で、眠(ねむ)っていた少年の長いまつげがかすかに震(ふる)えた。

ゆっくりと、あの灰青色の瞳(ひとみ)が開かれる。

「カナタくん！　迎(むか)えに来たよ！　遅(おそ)くなって……五年間も待たせて、本当にごめんね！」

カプセルの中のカナタが、息をのんだ。

その瞳(ひとみ)に、信じられないという驚(おどろ)きと、あふれる光が灯る。

一筋の涙(なみだ)がつうっとほほを伝い落ちた。

カナタは震(ふる)える指先で、紺色(こんいろ)のコートの内ポケットに手を入れた。

そして、大切に取り出したのは――五年のあいだ肌身離(はだみはな)さず持っていた、薄汚(うすご)れて毛羽立った、けれどあたたかい片方だけの赤い手ぶくろだった。

右手用の、小さな手ぶくろ。

その瞬間(しゅんかん)、こはるの左手にはまっていたポッケが、目のくらむような赤い光を放った。

「ポ、ポケーッ……！　ボクの、片っぽ……！」

カプセルのガラスを通り抜(ぬ)け、左右の赤い手ぶくろが、光の糸で強く結ばれた。

パリンッ！

巨大(きょだい)なガラス板が、きらきらと輝(かがや)く無数の光の粒(つぶ)となって砕(くだ)け散った。

カナタの身体がふわりと光に包まれ、床(ゆか)の上に降り立つ。

ポッケはこはるの手から飛び出すと、宙でくるくると回りながら大粒(おおつぶ)の涙(なみだ)をこぼした。

「思い出したポケ……！　ボクの持ち主は……こはるだったポケ！　ボクはずっと、こはるの手ぶくろだったんだポケぇぇぇっ！」

ポッケはこはるの胸へ勢いよく飛び込(こ)み、わんわんと声をあげて泣きじゃくった。

こはるはポッケを両手で優しく包み込(こ)み、胸に抱(だ)きしめた。

「ポッケ……ずっとそばにいてくれたんだね。気づかなくてごめんね。ありがとう……！」

そのとき――。

カチリ。

こはるのポケットの中で、重い金属音が響(ひび)いた。

カナタが体育館に残していった、銀色の懐中時計(かいちゅうどけい)。

五時ちょうどで止まっていた秒針が、奇跡(きせき)のように、力強い音を立てて動き出したのだ。

チクタク、チクタク、チクタク――！

五年のあいだ止まっていた時間が、いま、確かに動き始めた。

カナタが一歩、前へ踏(ふ)み出した。

その顔には、いつもの冷たさも、怪盗(かいとう)の仮面もなかった。

泣き虫だった五歳(さい)の男の子の面影(おもかげ)を残したまま、カナタは泣き笑いのような、どこまでも優しい顔で言った。

「……こはる」

生まれて初めて、カナタがこはるの名を呼んだ。

「迎(むか)えに来てくれて……ありがとう」

こはるは涙(なみだ)をぬぐい、満面の笑顔で力強くうなずいた。

「うんっ！　おかえり、カナタくん！」

だが、ふたりの奇跡(きせき)の再会を切り裂(さ)くように、すさまじい黒い嵐(あらし)が巻き起こった。

『許さない……許さないよぉぉぉっ！』

時計塔(とう)の吹(ふ)き抜(ぬ)け全体が、怒(いか)り狂(くる)う黒い霧(きり)で埋(う)め尽(つ)くされた。

巨大(きょだい)な少女の影(かげ)――ワスレナが、青いワスレナグサの花を激しく光らせながら叫(さけ)び声をあげる。

『どうせ、みんな忘れるんだ！　人間なんて身勝手だ！　なくしたときは大騒ぎ(おおさわぎ)するくせに、新しいものを手に入れれば、昔のことなんてきれいさっぱり忘れてしまう！　迎(むか)えになんて、誰(だれ)も来やしないんだ！』

床(ゆか)が激しく割れ、黒い霧(きり)の手が無数に伸(の)びて、ふたりを引き裂(さ)こうと襲(おそ)いかかる。

「カナタ！」

「うおおおっ！　トナカイ・スライディングだぜええっ！」

ドガァァン！

突如(とつじょ)、階段の踊(おど)り場から転がり込(こ)んできたタイガが、猛烈(もうれつ)なタックルで黒い霧(きり)の手をはね飛ばした。

「タイガ！？」

「ハア、ハア……追いついたぜ！　下の手ぶくろどもは、ぜんぶオレたちの敵じゃなかったぜ！」

タイガの後ろから、手帳を構えたアヤメが息を切らせて駆(か)け上がってきた。

足元には三毛ネコのミーコが寄り添(そ)っている。

「九条……犬飼……！」

カナタが目を見張ると、タイガが八重歯を見せてニッと笑った。

「よお、カナタ！　無事だったかよ！」

アヤメも乱れた前髪(がみ)を直しながら、りんとした声で言った。

「証拠(しょうこ)はそろったわ。ワスレナ、あなたの負けよ！」

『黙(だま)れ、黙(だま)れぇぇぇっ！　お前たちも、すべて忘れさせてやる！』

ワスレナの黒い霧(きり)が、津波(つなみ)となって押(お)し寄せる。

だが、こはるは逃(に)げなかった。

星のランタンを高く掲(かか)げ、一歩、また一歩と、巨大(きょだい)な闇(やみ)へ向かって歩みを進めた。

「こはる、危ないわ！」

アヤメの制止の声にも、こはるは立ち止まらない。

こはるの身体から、純白と夕焼け色の探偵(たんてい)ケープがふわりと広がり、頭上の星のティアラがきらめいた。

「忘れないよ」

こはるは、穏(おだ)やかな、けれど力強い声で言った。

「人は、忘れちゃう生き物かもしれない。わたしも、忘れん坊(ぼう)で、毎日たくさんの失敗をするよ。宿題も忘れるし、リコーダーも忘れるし、大事な約束まで忘れちゃった。……でもね、思い出そうとすることはできるの！」

ランタンの光が、温かい夕焼け色のドームとなって広がり、黒い霧(きり)を優しく包み込(こ)んでいく。

「忘れるのは、悪いことじゃないよ。でも、思い出す気持ちがあれば、心はまたつながるんだよ！」

こはるは、怒(いか)り狂(くる)う影(かげ)の少女に向かって、そっと両手を伸(の)ばした。

「わすれもの探偵団(たんていだん)が、みんなの持ち主を探すよ。どんなに遠くても、どんなに時間がかかっても、わたしが絶対に届ける。だから……もう、一人で泣かなくていいんだよ」

『う、うそだ……そんなの、信じるもんか……！』

ワスレナの影(かげ)が激しく震(ふる)えた。

そのとき、吹(ふ)き抜(ぬ)けの階段から、静かな足音が響(ひび)いてきた。

矢がすり模様の着物に、えんじ色のはかま。

わすれもの館の館長、シオリさんだった。

シオリさんは静かに歩み寄ると、震(ふる)える黒い霧(きり)の少女を、その柔(やわ)らかな腕(うで)でそっと抱(だ)きしめた。

「シオリ……さん……？」

ワスレナの重なり合った声が、かすかに震(ふる)える。

シオリさんは丸いメガネの奥(おく)の瞳(ひとみ)を潤(うるお)ませ、慈(いつく)しむように微笑(ほほえ)んだ。

「ごめんなさい、わたくしの影(かげ)。あなたを、こんなにも長いあいだ一人にしてしまって」

シオリさんの手から、藤色(ふじいろ)の温かい光があふれ出す。

「わたくしは、百年分のわすれものたちのことを、一度だって忘れたことはありませんのよ。駅長さんが旅立ったあの日から、ずっと……ずっと、あなたたちの帰りを祈(いの)り続けておりましたのよ」

『シオリ……シオリ……！』

ワスレナの目から、黒い涙(なみだ)ではなく、透(す)き通った青い光の粒(つぶ)がポロポロとあふれ出した。

黒い霧(きり)が、みるみるうちに浄化(じょうか)されていく。

ドロドロとした影(かげ)の身体が解け、何千、何万という淡(あわ)い水色の花びらへと姿を変えていく。

『……見つけて……くれて……ありがとう……』

重なり合っていた無数の声は、最後には、澄(す)み切った一人の少女の感謝の声となって響(ひび)いた。

サアァァァ……！

ワスレナグサの花びらが、光の竜巻(たつまき)となって時計塔(とう)の天井を突(つ)き破り、夕暮れの空へと舞(ま)い上がっていった。

花言葉は――『わたしを忘れないで』。

たそがれの国の暗い空が、まるで夜明けを迎(むか)えたように、温かい朝焼けの金色へと染まっていく。

「おかえり、わすれもの……！」

こはるが笑顔で空を見上げると、世界じゅうの止まっていた時計たちが、一斉(いっせい)にチクタクと音を立てて時を刻み始めた。

光に包まれて目を開けたとき、四人は月見坂の坂道の上に立っていた。

夕方五時十五分。

街灯がぽっぽっと灯り始め、商店街のちょうちんが初雪の舞(ま)う夜空を赤く照らしている。

冬祭りのにぎやかな太鼓(たいこ)や笛の音が、風に乗って聞こえてきた。

「も、戻(もど)ってきたのか……？」

タイガが自分の手を見つめ、それから町を見下ろして叫(さけ)んだ。

「戻(もど)ってきたんだ！　オレたち、帰ってきたんだぜ！」

「ええ。町の人たちの記憶(きおく)も、戻(もど)っているはずよ」

アヤメが手帳を閉じ、満足そうに微笑(ほほえ)んだ。

そのとき、坂の下からバタバタと激しい足音が駆(か)け上がってきた。

「カナタ！　カナタぁぁっ！」

息を切らせて走ってきたのは、紺色(こんいろ)のエプロンをつけた夜見ミチルさんだった。

その手には、きれいに編み上げられた、新品の紺色(こんいろ)とグレーのマフラーが握(にぎ)られていた。

「母さん……！」

カナタが駆(か)け出す。

ミチルさんはカナタの姿を見るなり、その場に崩(くず)れ落ちるようにして、息子を力いっぱい抱(だ)きしめた。

「カナタ……！　ああ、カナタ！　どこへ行っていたの！？　探したのよ、ずっと探していたのよ……！」

「母さん……ごめん、ごめんなさい……！」

カナタはミチルさんの胸に顔を埋(う)め、声をあげて泣いた。

ミチルさんは涙(なみだ)でぐしゃぐしゃの顔で笑いながら、震(ふる)える手で、編みたてのマフラーをカナタの首に優しく巻いてあげた。

「おかえり、カナタ。五年間も待たせて……本当にごめんね」

「ただいま、母さん……！　あったかいよ、すごくあったかい……！」

親子の抱擁(ほうよう)を、こはる、アヤメ、タイガは温かい涙(なみだ)を流しながら見守っていた。

タイガは「ううっ、よかったなあ、カナタぁ！」と、鼻のばんそうこうをぬらしながら自分の服の袖(そで)で豪快(ごうかい)に鼻をかみ、アヤメに「汚(きたな)いわよ、犬飼くん」とハンカチを投げつけられていた。

「おーい！　みんなーっ！」

さらに坂の下から、担任の森先生やクラスメイトたちが手を振(ふ)って駆(か)け上がってきた。

「夜見くん！　急にいなくなるから心配したんだから！」

「月曜日のサッカー、絶対に来いよな！」

みんなの笑顔が、カナタをあたたかく迎(むか)え入れた。

カナタが顔を上げ、こはるたちの元へ歩み寄ってきた。

首には、母の愛が詰(つ)まった新しいマフラー。

そして、その右手には――あの五年前の赤い手ぶくろが、誇(ほこ)らしげにはめられていた。

「こはる」

カナタは少し照れくさそうに、けれどまっすぐにこはるを見つめた。

「この手ぶくろ、ずっと大切にする」

こはるは左手を掲(かか)げた。

その手には、赤い毛糸玉のポッケが、ちょこんと乗っている。

「ボクはこはるの相棒ポケ！　これからも、たくさんのわすれものを持ち主に届けるんだポケ！」

ポッケが得意げに胸を張ると、カナタがふっと口元を緩(ゆる)めた。

「ああ。よろしくな、毛糸玉」

「毛糸玉じゃないポケ！　ポッケさまと呼ぶポケ〜！」

みんなの笑い声が、夜空に溶(と)けていった。

夜空からは、チラチラと美しい初雪が降り注ぎ、町を優しく白く包み込(こ)んでいた。

それから、数日後の日曜日。

冬の澄(す)み渡(わた)る青空の下、坂の上の赤レンガの洋館の前に、元気な声が響(ひび)き渡(わた)った。

「わすれもの探偵団(たんていだん)、本日も営業中だよ！」

こはるが笑顔で立てかけた新しい木製の看板には、こう書かれていた。

『月見坂わすれもの相談所（わすれもの探偵団(たんていだん)）』

いまや、わすれもの館は夕方五時だけでなく、昼間でも誰(だれ)でも立ち寄れる、町のみんなの憩(いこ)いの場所になっていた。

テラスのテーブルでは、アヤメが万年筆(まんねんひつ)を走らせて新しい依頼(いらい)ノートを整理している。

「今週の依頼(いらい)は、お隣(となり)の駅で落とされた定期入れと、商店街の八百屋さんの愛猫(あいびょう)の鈴(すず)よ」

「オレの鼻にかかれば、鈴(すず)のありかなんて一発で見つけてやるぜ！」

タイガがサッカーボールをリフティングしながら威勢(いせい)よく叫(さけ)ぶ。

「調子に乗るなよ、犬飼。前回の落とし穴を忘れたのか」

カナタがほしかわベーカリーの焼きたてメロンパンをかじりながら、クールにつぶやいた。

「カナタ！　メロンパンのはしっこはボクのものポケ！　一口よこすポケ！」

ポッケがカナタの肩(かた)によじ登り、パンをめぐって大騒ぎ(おおさわぎ)を繰(く)り広げている。

シオリさんが楽しそうに紅茶を注ぎ、三毛ネコのミーコが日だまりで気持ちよさそうに丸くなっていた。

「ふふっ！」

こはるは黄色いケープを翻(ひるがえ)し、海を見下ろす坂道を見つめた。

坂の向こうには、きらきらと光る青い海と、大好きな月見坂の町が広がっている。

もし、誰(だれ)かが大切なものをなくしてしまっても、もう大丈夫(だいじょうぶ)。

いつだって、こはるたちが迎(むか)えに行くから。

「その"わすれもの"、わたしたちが届けます！」

こはるの声が、冬晴れの空高く、どこまでも響(ひび)き渡(わた)っていった。

カタン。

そのとき、門柱につけられたアンティークの郵便ポストに、小さな音がして何かが落ちてきた。

新聞でも、商店街のチラシでもない。

厚手の白い封筒(ふうとう)。

そこには、見たこともない銀色の星の封(ふう)ろうが押(お)され、消印には、地図のどこにも載(の)っていない、見知らぬ町の名前が記されていた。
