# 翻訳用語集 / Translation Glossary

All translations must keep these names and terms consistent across all 12 episodes and the site UI (content/i18n/<lang>.json).
English is the reference; translators for other languages should create natural equivalents and use them consistently (Japanese-origin personal names stay as names, in the language's usual transliteration: e.g. zh uses the kanji names, ko uses Hangul transliteration).
